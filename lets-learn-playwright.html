Module 1 · Lesson 1.1

Environment Setup & Your First Test

🔧 Tools & setup

  • Python 3.9+ already on your machine (check: python --version)
  • pip install pytest-playwright
  • playwright install — pulls the Chromium/Firefox/WebKit binaries (this is the big one, ~500MB, let it run)
  • A code editor — VS Code recommended for the Playwright test-runner extension

📖 Overview

Playwright is a browser automation library — it drives a real browser (Chromium, Firefox, or WebKit) programmatically: click things, fill forms, read text, assert what's on the page. What makes it different from older tools like Selenium is auto-waiting: Playwright automatically waits for an element to be actionable (visible, stable, enabled) before interacting with it, instead of you writing manual sleep() calls or explicit wait conditions everywhere. That single design choice is why Playwright suites are dramatically less flaky than Selenium suites out of the box — it's solving the exact "elements aren't ready yet" problem that causes most flaky-test pain in your Selenium/Cucumber world at work.

A test in pytest-playwright is just a Python function that takes a page fixture — pytest and the plugin handle spinning up the browser for you. You navigate, interact, assert. That's the whole loop for now.

🧩 Real-world scenario

Picture handing a QA analyst on your team a manual test case: "Go to the login page, enter valid credentials, confirm you land on the dashboard." Today's lesson is that exact test case, written as code instead of a step sheet — the translation you'll be doing constantly if Playwright ever becomes part of your team's stack.

✍️ Hands-on exercise

Write this test

Using playwright.dev's public demo site (https://playwright.dev itself works fine), write a test that:

  1. Navigates to the Playwright docs homepage
  2. Clicks the "Get started" link
  3. Asserts the resulting page's heading contains "Installation"

Run it with pytest --headed so you can actually watch the browser do it — that visibility matters more than you'd think when you're new to this.
